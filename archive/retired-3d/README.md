# Retired 3D presentation — 23 October 2026

These earlier room and match-rendering experiments are archived for reproducibility.
They are not loaded by index.html, offered in the game, or staged into the desktop runtime.
Their standalone geometry regressions remain as historical checks. This is not another playable presentation mode.

The active game uses clubhouse-theme.js for the club and MatchBroadcastRenderer for the 2D rink.
match-presentation.js owns the retained snapshot interpolation and recorded tactical overlays;
the match engine, saves, calendar, coaching consequences and random stream are unchanged.

The files can be recovered from this archive or Git history. No career saves were deleted.
